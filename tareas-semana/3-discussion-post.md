# Initial Post

Chapter 7 of College Success argues that college develops several kinds of higher-level thinking, including creative, analytical, critical, and problem-solving thinking, along with metacognition and information literacy (Baldwin, 2020). In my first-semester composition course, I was assigned an annotated bibliography of five sources for a research paper. At the time, it seemed pointless. I already knew how to search, and each entry felt like paperwork. I wondered why I could not simply list the first results my search returned.

Looking back, the assignment gave me practice with several of the thinking skills Baldwin (2020) describes. Summarizing each article required analytical thinking, because I had to separate a source into its component parts and explain how those parts connected to my topic. Deciding whether a source was current and credible required information literacy and critical thinking, including checking the author's credentials and possible bias. The Vanderbilt University Center for Teaching (n.d.) notes that the revised Bloom's taxonomy ranks analyzing, evaluating, and creating above simply remembering facts.

These habits will matter in computer science or web design. When I build web pages, I often compare developer documentation and tutorials to decide which are accurate and up to date, the same process I used for my sources. Writing a short annotation also resembles writing code comments that explain why a solution works, which helps when I return to a project months later. Baldwin (2020) lays out problem-solving as a sequence: identify the issue, consider other perspectives, generate several possible results, evaluate them, select the best, and set action items. I use that sequence when debugging a broken layout. The bibliography was not pointless after all. It taught me to examine a source before I trust it.
