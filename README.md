# Cuarto reorganizado

Maqueta 3D interactiva (antes / después) de la redistribución del cuarto, con plano acotado, lista de compra y pasos.

- `index.html`: ábrelo en cualquier navegador (necesita internet para cargar Three.js).
- `cuarto-3d.html`: misma página en formato Artifact de claude.ai.

Las medidas (≈ 340 × 330 cm) son estimadas a partir de fotos; mide antes de comprar.
